# oura_stress

A personal, self-hosted command-line tool that reads the Oura `daily_stress` summary
from the user's own Oura account and shows a macOS notification when stressed time is
building during the workday.

- Source code: <https://github.com/cachedout/oura_stress>
- [Privacy Policy](privacy.md)
- [Terms of Service](terms.md)

The tool runs entirely on the user's own computer. There is no hosted service, no
account system, and no server operated by the developer.
